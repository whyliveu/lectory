# Lectory MVP — понятный план

## Выбранный стек (самый простой для старта)
1. **Next.js** — сайт и сервер в одном проекте.
2. **Supabase** — облачная база данных + хранение файлов.
3. **Tailwind CSS** — быстро сделать аккуратный современный UI.

## Почему это удобно новичку
- Меньше сервисов и "склейки" между ними.
- Можно запускать локально одной командой `npm run dev`.
- Легко перейти от демо к реальному продукту.

## Этапы MVP
1. **Каркас проекта + UI-стиль** (сделано в этом коммите).
2. **Подключить Supabase** и создать таблицы.
3. **Форма создания дисциплины**.
4. **Форма загрузки SRT + метаданные** (дисциплина/преподаватель/дата).
5. **Обработка SRT**: извлечение чистого текста и генерация структуры лекции.
6. **Список лекций + фильтр по дате/дисциплине/преподавателю**.
7. **Страница лекции**: summary, outline, key points, mentions, сырой SRT.
8. **Редактирование полей**: title/date/discipline/teacher.
9. **Демо-наполнение** двумя реальными лекциями.

## Минимальная структура данных (для MVP)
- `disciplines`: `id`, `title`, `teacher_name`.
- `lectures`: `id`, `discipline_id`, `date`, `generated_title`, `short_description`, `status`.
- `lecture_summaries`: `lecture_id`, `full_summary`, `main_outline`, `key_points`, `mentions`.
- `lecture_files`: `lecture_id`, `file_name`, `file_type`, `file_url`, `raw_text`.
