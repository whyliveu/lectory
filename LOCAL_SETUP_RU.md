# Lectory — как запустить проект локально (очень просто)

Ниже инструкция для новичка на **Windows** и **macOS**.

## 0) Что это значит «локально»
Локально = проект работает на вашем компьютере, обычно по адресу:
`http://localhost:3000`.

---

## 1) Установить нужные программы

### Обязательно
1. **Node.js LTS (20.x)**
   - Сайт: https://nodejs.org
   - Нажмите кнопку **LTS** и установите.
2. **Git**
   - Сайт: https://git-scm.com/downloads
   - Скачайте и установите с настройками по умолчанию.
3. **Visual Studio Code (VS Code)**
   - Сайт: https://code.visualstudio.com/

### Проверка, что всё установилось
Откройте терминал и выполните:
```bash
node -v
git --version
```
Если видите версии (например `v20...`), всё ок.

---

## 2) Скачать проект к себе на компьютер

Есть два простых способа.

### Способ A (самый простой для новичка): через GitHub ZIP
1. Откройте страницу репозитория на GitHub.
2. Нажмите зелёную кнопку **Code**.
3. Нажмите **Download ZIP**.
4. Распакуйте архив в удобную папку, например:
   - Windows: `C:\Projects\lectory`
   - macOS: `/Users/<ваше_имя>/Projects/lectory`

### Способ B (правильный рабочий): через `git clone`
В терминале перейдите в папку, где хотите хранить проект, и выполните:
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd lectory
```

---

## 3) Открыть проект в VS Code
1. Откройте VS Code.
2. Нажмите **File → Open Folder...**
3. Выберите папку проекта `lectory`.
4. Откройте встроенный терминал: **Terminal → New Terminal**.

---

## 4) Установить зависимости и запустить
Во встроенном терминале VS Code (в папке `lectory`) выполните:
```bash
npm install
npm run dev
```

После запуска увидите что-то вроде:
`Local: http://localhost:3000`

Откройте этот адрес в браузере.

---

## 5) Что вы должны увидеть
- Тёмный интерфейс Lectory.
- Левую панель с демо-лекциями.
- Правый блок «Шаг 1 MVP / Каркас готов».

## 6) Частые ошибки и как исправить

### Ошибка: `npm: command not found` или `node: command not found`
Причина: Node.js не установлен или не добавился в PATH.
Решение: переустановить Node.js (LTS), перезапустить терминал.

### Ошибка доступа при `npm install` (403/407/ETIMEDOUT)
Причина: сеть, прокси, VPN, корпоративные ограничения.
Решение:
1. Выключить VPN/прокси (или настроить правильно).
2. Повторить `npm install`.
3. Если вы в корпоративной сети — попробовать домашний интернет.

### Ошибка: порт 3000 занят
Решение:
- запустить на другом порту:
```bash
npm run dev -- -p 3001
```
И открыть `http://localhost:3001`.
